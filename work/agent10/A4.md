# A4 — title-indexed wikilinks (cheap falsification)

Executed 2026-08-29 on local **enwik8** (100,000,000 B, MD5
`a1fa5ffddb56f4953e226637dabbb36a`) and **enwik8.3m**. No codec. No 3 MB
fxcm. No enwik9.

Script: `a4_enwik8.py`. Table: `a4_enwik8.json`.

Not a record. Not a full-stack archive number.

A2 killed per-page **list lex** of link titles. A3 killed dump aliases,
second WRT crumbs, and fair table/infobox reorders. A4 is a different
redundancy: the dump is a graph. Every ns0 `<title>` is already in-band.
PHDA9 (`encode_txt_wit`) packs headers, entities, and the `hent9`
bracket-density trick; it does **not** extract wikilinks. `payload_lex`
does not reorder them. fxcm_v26 *parses* `[[ ]]` for context and still
encodes the target **string**. Replace a resolved target with
`0x01+uleb(page_index)` (S1≈0). Inverse: parse titles, then expand
marks. Not E41 (no rare-token dict). Not mixer slots.

Kill rule: expected enwik9 |ΔS| in the **tens of KB** after WRT + match
overlap.

## Generic-compressor ranking (E41 filter)

Replace only the **target** slice of resolved `[[Target]]`; keep
brackets, `#fragment`, and `|display`. Whole-file compare is the
honest gate.

| stream | raw Δ | zlib9 Δ | lzma6 Δ |
|---|---:|---:|---:|
| enwik8 whole dump | +967,199 | **+25,266** | not run (zlib ≪ 80 KB gate) |
| enwik8 all `[[…]]` spans | +967,199 | +83,675 | **+17,264** |
| enwik8 resolved targets only (isolated) | +967,199 | +213,524 | +105,584 |
| live uleb vs shuffled page-ids | ~0 | −248 | **−3,320** (live slightly better) |
| enwik8.3m whole dump | +6,614 | **−34** | — |

Isolated-target lzma (+106 KB) is a mirage: it throws away the English
the rest of the file was using as context. Whole-file zlib keeps
**2.6%** of the raw cut. Span lzma keeps **1.8%**. Same failure mode as
E41: a pointer alphabet generic compressors reject.

Shuffled IDs ≈ live IDs. The graph is not a secondary code. The only
effect is “short tokens instead of English,” and zlib/lzma do not want
that.

WRT-aware (2 B per dic-word, optimistic for the **pointer**): pointer
beats that model on 52,491 / 112,935 links, **+187,663 B**. Do not
scale that number — whole-file zlib is +25 KB.
