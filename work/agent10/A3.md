## Hybrid parsed-wiki fields (fair, same bytes)

The first pass mixed layout with deleted markup (table alt dropped `{|`
syntax; infobox alt dropped repeated keys). Re-ran with **the same cell /
value bytes**, only order:

| layout | raw | zlib Δ | lzma Δ |
|---|---:|---:|---:|
| wikitable cells, row-major vs column-major (1496 tables, 2.40 MB) | 2,401,792 | +7,609 | **+10,040** |
| infobox values, dump-order vs grouped-by-key | 302,100 | +6,355 | **+3,536** |

Wikitables are 3.07 MB of markup in the dump (3.1% of file) but almost
all unique. Columnar clustering is real and **small**. ×10 → ~100 KB
lzma before fxcm table/template contexts (v26 already gates tables) and
before a reversible restore map. After 50–80% overlap: **tens of KB**.

Infobox-by-key is **+3.5 KB** lzma on the same 302 KB of values. A2
already killed whole-blob lex (30–150 KB expected). This is the same
mass, weaker.

**KILL both as A.**
